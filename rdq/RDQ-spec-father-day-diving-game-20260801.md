# RDQ 需求規格：父親節潛水闖關網站

## 一句話任務
設計一個父親節主題的潛水闖關網站，透過尋找裝備、回憶錄答題、拍照留念，最後呈現明信片祝福。

## ✅ 已確認
- 目標：設計父親節闖關網站（Ⅰ）
- 流程：開始→尋找裝備→回憶錄答題→得取裝備→重複直到所有裝備獲取→前往海水潛水→拍照→泡泡轉場→明信片祝福（Ⅰ）
- 使用人數：只有我一個人在操作（Ⅲ）
- 部署方式：部署到 GitHub Pages，發網址或 QR Code（Ⅲ）
- 裝置與網路：學生自己的手機（含舊 Android、iOS Safari）（Ⅲ）
- 裝備數量：**六件**（Ⅲ）
- 題目類型：**回憶錄形式，點選跑出過去照片紀錄（照片由使用者提供）**（Ⅲ）

## ❓ 假設（未確認，已採預設值，隨時可推翻）
- 六件裝備具體為何→ 預設採 **蛙鏡、呼吸管、蛙鞋、潛水衣、氣瓶、面鏡**（待確認）
- 回憶錄照片格式→ 預設採 **JPG/PNG 圖片**，由使用者提供
- 拍照方式→ 預設採 **上傳照片或選擇預設圖片**，主角與海中生物合照
- 明信片內容→ 預設採 **手寫祝福字句、地址、郵戳**，可自訂
- 網站風格→ 預設採 **海洋藍色調，活潑可愛風格**

## ➕ 已採納（象限Ⅳ）
- 把可調參數（題目、顏色）集中到單一 config 檔，加一頁 README 寫清楚怎麼改題目
- 先做一版「所有段落都在、細節從簡」的粗胚給你看方向，確認後再精修

## ❌ 排除項（明確不做）
- 實際拿一台 iPhone 和一台舊 Android 測過再上場
- 為現場準備斷線備案：一個不依賴網路、雙擊就能開的單檔 HTML
- 動手前先盤點有沒有現成的可以直接改

## 📋 一段式需求規格
設計一個父親節主題的潛水闖關網站，部署到 **GitHub Pages**，主要供學生用手機（含舊 Android、iOS Safari）遊玩。網站流程如下：開始時發現潛水裝備散落在不同地點，需尋找裝備；找到後點選裝備，進入回憶錄答題環節（**點選跑出過去照片紀錄**，照片由使用者提供），答對後即可獲得裝備；重複尋找與答題直到所有 **六件** 裝備獲取（預設：蛙鏡、呼吸管、蛙鞋、潛水衣、氣瓶、面鏡）；前往海水潛水，出現潛水畫面，進行拍照（照片內容為主角在照片中開心和海中生物一起拍照）；點選後出現 **HAPPY FATHER'S DAY** 造型泡泡，從畫面下方飄上，覆蓋整張畫面進行轉場；最後出現明信片背面，內容為手寫祝福字句、地址以及郵戳。技術需求：純前端靜態網站，可調參數（題目、顏色）集中到單一 **config 檔**，附 **README** 說明如何修改題目與重新部署。

- [ ] 題目（照片）可從 config 檔輕鬆修改
